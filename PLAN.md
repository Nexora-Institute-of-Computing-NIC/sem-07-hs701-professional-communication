# HS701 — Professional Communication — PLAN

**Semester:** 7 · **Credits:** 2 · **Level:** Advanced-Professional
**Theory:** 15 hrs · **Practice:** 15 hrs · **Tools:** Video recording, presentation software, mock interview platforms

## Syllabus

### Unit 1 — Communication at Work (5 lectures)
1. Why professional communication differs from academic writing
2. Audience-first communication
3. Written vs verbal vs visual — choosing the medium
4. Asynchronous communication — email, Slack, docs
5. Meeting etiquette and running effective meetings

### Unit 2 — Technical Presentations (5 lectures)
1. Structuring a technical talk — the three-act form
2. Slide design for technical content — what to include, what to cut
3. Live demos — planning for the inevitable failure
4. Q&A handling under pressure
5. Presenting to non-technical stakeholders

### Unit 3 — Technical Interviews (5 lectures)
1. The interview landscape — phone screen, technical, behavioural, system design
2. Coding interviews — think-aloud, complexity, edge cases
3. System design interviews — the four-section framework
4. Behavioural interviews — STAR method with real examples
5. Negotiation — salary, equity, role, and timing

### Unit 4 — Written Communication for Engineers (5 lectures)
1. Technical design documents — structure and clarity
2. Incident reports — what happened, why, prevention
3. Decision records — recording trade-offs
4. Feedback — giving and receiving without friction
5. Writing for asynchronous review — PR descriptions, RFCs

### Unit 5 — Career Communication (5 lectures)
1. LinkedIn and GitHub profiles as a professional signal
2. Personal brand — what you want to be known for
3. Networking — how to build relationships that outlast the job
4. Mentorship — finding one, being one
5. The long game — visibility, reputation, opportunity

## Practical Labs (15)

1. Record a 1-minute self-introduction video — self-critique
2. Write a professional email and a Slack message for the same update
3. Run a mock meeting with a peer — agenda, minutes, action items
4. Design a 5-slide technical presentation on a project you built
5. Deliver the 5-minute talk, record it, review
6. Design and deliver a live demo — including a planned failure
7. Q&A stress test — handle 5 hostile questions
8. Coding interview mock — 45 minutes, recorded
9. System design interview mock — 45 minutes
10. Behavioural interview mock — 3 STAR stories rehearsed
11. Write a one-page design document for a real decision
12. Write an incident postmortem for a simulated incident
13. Give written feedback on a peer's pull request — kind, specific, actionable
14. Rewrite a poor LinkedIn profile into a strong one
15. Negotiation role-play — offer on the table, negotiate the package

## Assignments

1. Communication audit — review your own past emails and improve three
2. Presentation portfolio — deck + video of one delivered talk
3. Interview pack — 5 STAR stories + recorded mock interview
4. Written communication — design doc + postmortem
5. Professional presence — polished LinkedIn + GitHub profiles
